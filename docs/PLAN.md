## How to read this

* **Group** is a wave. Group A runs first, then B, and so on. Tasks in the same group touch different files and can run at the same time, once their own dependencies are done. A task may start before its group when all its dependencies are done, but **a task never starts while another running task lists any of the same files**. This matters most for `src/main.ts`, `src/game/game.ts`, `src/ui/hud.ts`, `src/app/screens.ts` and `scripts/check-dist.mjs`.
* When a group is big, start the tasks of the earliest milestone first.
* **Files**: the only files the task may create or change. A listed `x.ts` includes its test `x.test.ts` next to it. A CSS file is imported by the `.ts` file of its screen (`import './x.css'`), so no other file changes for it. E2e hooks are registered inside the feature's own file, so no extra hook file is needed. In a parallel group, `CHANGELOG.md`, `README.md` and `docs/ARCHITECTURE.md` are updated by the operator from the developer's report.
* **(stub)** after a file means: create it as a placeholder that shows "Komt nog" with the final exported function. A later task replaces it.
* **Acceptance** lists PRD `AC` numbers. Each task proves them with tests (unit or e2e) unless marked (iPad), which is a check by hand on the real iPad.
* Every task: `./scripts/check.sh` passes, tests added, no new packages (only T1 edits `package.json`).

At 600 000 ms it is due: if `remainingPlayMs()` is under 60 000 it waits for `onBreakFinished` (wired in `boot.ts` next to `resetPlayTimer`), then 30 000 ms of play time, then it comes whatever the next break is. No valid spot: try again every 5000 ms of play time. The moment a bubble shows, the clock is set to 0 and saved, so a reload during a visit gives no instant second bubble. Saved with `updateMonsters` at most once per whole second. Spot: 6 to 10 blocks along the kid's view on the ground plane at eye height, a few yaw offsets, the cell is air (overlay aware), in the world, and a ray from the eye reaches it with no solid block. The bubble is drawn and hit tested at least 80 points wide (scale by distance). Every live clock (float in, 60 s, Klodder's 5 minutes, the 4 s nibble wait, the Moed bar, restores) runs on the game loop `dt`, which stops in every pause state. Hooks: `monsterState()` (phase, position, ages, nibbled cells, Moed, hidden count), `bubbleClockMs()`, `setBubbleClockMs(ms)`, `spawnBubble()`, `spawnKlodder()`, `teaseNow()`.
* **V18b nibble rules.** A cell may go when: it is solid and not air, oersteen, water, lava or fire; it and every cell within 3 along each axis are `isUnchanged` (343 O(1) lookups, no diff scan, no index); it is outside every village site (`inRegion(siteRegion(site), x, z)`); it is not within 1 block of the kid's box or any dino, egg, chicken, villager or knight box; it has air above it. Klodder walks to it with `stepToward` at 1.5 blocks per second. At most one nibble per 4000 ms of loop time, at most `MAX_NIBBLES` = 20, then he only teases. When the kid's box comes within 1 block of his, he hops to a free spot 3 to 5 blocks from the kid, so the boxes never overlap. Restores: every hidden cell comes back one at a time, spread over about 2 s (interval `min(150, 2000 / n)` ms); an occupied cell retries every 1000 ms; a cell no longer hidden (the kid built there) is dropped. Tired: 300 000 ms out, "Ik ben moe", fixed.
* **V18c flee.** `DinoState` gets an optional, never saved `flee: { x, z, left, backX, backZ }`; `stepDino` walks straight to it at 3 blocks per second through `physics` (hazards stay walls), for at most 3 s, then walks back to within 3 blocks of `backX, backZ` (where it stood when teased) and carries on in its mode. The path probe samples the straight line every 0.25 block: step up at most 1, drop at most 1, no water, lava or fire at the feet or the ground, inside the world, and the end cell has at least one open neighbour. No such spot in 8 tries: jump and sound only. Product note: "within 3 blocks of its spot" in AC220 is read as the spot where the roaming animal stood when teased, because since decision 128 a Vrij rondlopen animal is anywhere within 12 blocks of its stay spot (see decision 135).
* **V18d Moed.** "Within N blocks" is along each axis. Follow and stay knights notice Klodder within 8, guard knights within 16, and get `chase` set to his position each frame. A knight within 1.5 blocks pokes ("Tok!"). While someone pokes, Klodder stands still and does not nibble. The bar fills at `min(pokers, 3)` per second, capped at 10 per second, full at 30, and keeps its value when no one pokes. Full: "Wegwezen!", "Doei!", leave with every block back, every `chase` set to null. Hint: at the first Klodder ever, `hintShown` becomes true and is saved; the text shows only when the kid owns no knight then.
