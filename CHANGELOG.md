# Changelog

Written so kids can read it too.

## Unreleased

* The project is set up: it builds, it has tests, and it opens in an iPad browser test.
* The world is built from a fixed seed: hills, grass, sand, trees and stone, with an unbreakable oersteen floor.
* The game can now save safely on the iPad. A save that gets cut off never breaks the old one.
* The app now fits the iPad like a real app: no zooming, no text selection, a friendly 'Draai je iPad' message in portrait, and a dino icon for the home screen.
* The world now has painted blocks: grass, stone, glass, wool and more. Only the sides you can see are drawn, so the game stays fast.
* You can walk around, jump up onto a block, and reach blocks up to 6 steps away. You can't walk out of the world.
* Walk with one thumb and look around with the other hand. Tapping a button never turns the camera by accident.
* You can now walk around the 3D world: move with the left thumb, look around with the right, and tap Spring to jump up a block.
* You can mine and build! Tap a block to break it, or put a new block next to it. Pick your block in the bar at the bottom, or choose one from "Alle blokken". Blocks pop and make a sound.
