# 't Kofschip: where the content comes from

Source: the founder's request on 2026-10-19 ("maak module met kofschip"). No workbook pages. All questions are newly written.

| Topic | Skills | Question styles |
|---|---|---|
| `verleden-tijd` | `kofschip-vt`, `meervoud-vt` | type the past tense, pick the right form, find the wrong word |
| `voltooid-deelwoord` | `kofschip-vd`, `zonder-ge` | type the voltooid deelwoord, pick the right form, find the wrong word |
| `lastige-gevallen` | `v-z` (verven, reizen), `t-d-stam` (zette, landde, gezet, gewacht) | type the form, pick the right form, find the wrong word |

Only weak (regular) verbs: strong verbs like lopen or slapen do not follow 't kofschip and are left out on purpose.

Overlap: the built in Cito module (`ww-verleden`) and Taal E6 (`werkwoordspelling`) also practise 't kofschip. This module is only about 't kofschip, with more practice per rule.

Exams: Toets 't kofschip M6 (15 questions) and Toets 't kofschip E6 (30 questions).

The content still needs one check by a teacher or parent (AC124).
