# Factory feedback: minespel, 2026-11-06
Source factory: dalhhorn-ship-it/danfactory (bf63299). For its inbox.

## F1: pre_compact.py drops the first letter of the first changed file
* Area: hook
* Template file: .claude/hooks/pre_compact.py
* What happened: the snapshot showed `claude/settings.json` for ` M .claude/settings.json`.
* Evidence: `git()` returns `p.stdout.strip()`, which strips the leading space of the first `git status --short` line, and then `l[3:]` cuts one character too many.
* Proposed change: `return p.stdout.rstrip()` in `git()`.
* Impact: low
* Confidence: reproduced

## F2: adopt has no "already has a factory" mode
* Area: skill
* Template file: plugin/skills/adopt/SKILL.md, scripts/adopt.py
* What happened: minespel already had agents, skills, CI, a PRD gate and STATUS. A full adopt would add 72 files and 18 agents next to them. We picked two parts by hand.
* Proposed change: an a la carte mode (`adopt.py --only hooks:context,guard-large-read`) and a scan check that warns when a project already has `.claude/agents` and its own CLAUDE.md process.
* Impact: medium
* Confidence: once
