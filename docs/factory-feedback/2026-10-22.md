# Factory feedback: minespel, 2026-10-22
Factory started: 2026-10-17
App result: 3 releases shipped (0.1.0, 0.2.0, 0.3.0), 162 ACs. Founder says CI, QA and updates are too slow and too costly.

## F1: Small releases need a fast lane
* Area: skill
* Template file: template/.claude/skills/release/SKILL.md, template/.claude/skills/ship/SKILL.md
* What happened: a 3 task release took 18 minutes to code and over 2 hours to ship.
* Evidence: git log for 0.2.0 and 0.3.0.
* Proposed change: a release of 3 tasks or fewer uses one developer, no architect review, no scribe agent (the operator writes the CHANGELOG line), and qa writes tests only for the new ACs. Commit locally, push once when the release is ready, open one pull request.
* Impact: high
* Confidence: repeated

## F2: Too many CI runs
* Area: ci
* Template file: template/.github/workflows/ci.yml, template/CLAUDE.md
* What happened: every docs commit started a full CI run. Runs queued up (146 to 148 at once).
* Evidence: friction 2026-10-19, 8 of 12 commits in 0.3.0 were docs only.
* Proposed change: CI skips pushes that only touch docs. Push at the end of a release, not per task. Heavy UI review tests run only on main and before a ship.
* Impact: high
* Confidence: repeated

## F3: Run browser tests locally, not by trial in CI
* Area: stack
* Template file: template/CLAUDE.md, template/scripts/check.sh
* What happened: the cloud session could not download WebKit, so every e2e mistake cost a 6 minute CI round.
* Evidence: 4 friction rows on test timing and guessed selectors.
* Proposed change: tell the founder on day one to allow cdn.playwright.dev and playwright.azureedge.net in the cloud environment. check.sh runs e2e for changed specs locally before a push.
* Impact: high
* Confidence: repeated

## F4: Stop polling CI
* Area: skill
* Template file: template/.claude/skills/ship/SKILL.md, template/CLAUDE.md
* What happened: the operator kept checking CI every few minutes, which costs tokens while nothing changes.
* Evidence: founder screenshot, "check back in about 8 minutes".
* Proposed change: after pushing, subscribe to the pull request and end the turn. CI results wake the session.
* Impact: medium
* Confidence: repeated

## F5: Docs grow until every agent reads 3000 lines
* Area: template
* Template file: template/docs/PRD.md, template/.claude/agents/*.md
* What happened: PRD 796 lines and 162 ACs, 89 decisions. All agents reread them.
* Evidence: wc -l docs.
* Proposed change: when a release ships, move its PRD section to docs/releases/vN.md. Agents get the core PRD and the current release section only. Decisions older than the last release go to an archive file.
* Impact: medium
* Confidence: once

## F6: Approval hook missed the Approve answer
* Area: gate
* Template file: template/.claude/hooks/prd-approve.sh
* What happened: the founder picked Approve but no stamp was written.
* Evidence: friction 2026-10-22.
* Proposed change: match any question that mentions the PRD or a release and an answer that starts with Approve, not one exact question text.
* Impact: medium
* Confidence: once
